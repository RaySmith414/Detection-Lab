# Attack scenarios

Generated by `python -m detlab build`. Do not edit it by hand.

`attack-simulator/simulator.py` plays six attack scenarios and writes the events a Windows host would log. This page shows what the lab's Sigma rules make of them. The simulator runs with a fixed seed (7), so the events below are the same on every run.

The scenarios are older than the rules. Run against them, the first 37 rules fired on 7 kinds of step and missed whole scenarios. The rules written to close those gaps are part of the lab now, each with its own samples in `simulations/events`.

A single-event rule fires on 79 of the 185 events. The other events are steps that look ordinary one at a time (a failed logon, a DNS lookup) or that no rule covers yet. They are listed as not detected instead of being left out.
