# Exercises

Generated by `python -m detlab build` from `attack-simulator/scenarios/scenarios.yaml`. Do not edit it by hand.

## Hunting exercises

Start the stack, load the data with `python -m detlab siem load` and work in Kibana Discover on the data view *Detection Lab: attack simulator scenarios*. Each exercise has hints and, further down, EQL queries that solve it. `python -m detlab siem exercises` runs those queries and prints how many events each one finds.

### Exercise 1: Hunt for Initial Access

**Objective:** Identify the initial compromise vector

Hints:

- Look for Office applications spawning suspicious processes
- Check for encoded PowerShell commands
- Review network connections from unusual processes

<details><summary>Queries that solve it</summary>

```eql
any where event.code == "1" and process.parent.executable : "*Office*" and process.executable : "*powershell.exe"
any where event.code == "1" and process.command_line : "* -enc *"
```

</details>

### Exercise 2: Detect Persistence Mechanisms

**Objective:** Find all persistence mechanisms established

Hints:

- Check registry Run keys
- Look for new scheduled tasks
- Review service installations

<details><summary>Queries that solve it</summary>

```eql
any where event.code == "13" and registry.path : "*\\CurrentVersion\\Run\\*"
any where event.code in ("4698", "7045")
```

</details>

### Exercise 3: Track Lateral Movement

**Objective:** Map the attacker's movement through the network

Hints:

- Look for SMB connections to multiple hosts
- Check for remote service installations
- Review logon events across systems

<details><summary>Queries that solve it</summary>

```eql
any where event.code == "3" and destination.port == "445"
any where event.code == "7045" and winlog.event_data.ServiceName == "PSEXESVC"
```

</details>

### Exercise 4: Identify Data Exfiltration

**Objective:** Detect and quantify data exfiltration attempts

Hints:

- Look for unusual DNS query patterns
- Check for large outbound transfers
- Review archive tool usage

<details><summary>Queries that solve it</summary>

```eql
any where event.code == "22" and dns.question.name : "*.data.evil-cdn.example.org"
any where event.code == "1" and process.executable : ("*\\7z.exe", "*\\rar.exe")
```

</details>

## Attack chains to read through

Four chains from first access to impact, with the technique of each step and what it leaves in the logs. They are reading material for planning detections. The simulator's six scenarios cover their building blocks, not these chains step by step.

### Phishing to compromise

Complete attack chain from initial phishing email to domain compromise. Mimics a typical APT attack pattern.

Difficulty: advanced. Estimated time: 30m.

| Step | Name | Technique | What to look for |
| --- | --- | --- | --- |
| 1 | Phishing Email Delivery | [T1566.001](https://attack.mitre.org/techniques/T1566/001/) | Word document with macros opened<br>Sysmon Event ID 1 - WINWORD.EXE spawning child process |
| 2 | Macro Execution | [T1204.002](https://attack.mitre.org/techniques/T1204/002/) | WINWORD.EXE spawning powershell.exe<br>Encoded PowerShell command<br>Network connection to external IP |
| 3 | Payload Download | [T1105](https://attack.mitre.org/techniques/T1105/) | PowerShell making HTTP request<br>File created in Temp directory<br>Suspicious DNS queries |
| 4 | Persistence Establishment | [T1547.001](https://attack.mitre.org/techniques/T1547/001/) | Sysmon Event ID 13 - Registry modification<br>Run key pointing to malware |
| 5 | Credential Dumping | [T1003.001](https://attack.mitre.org/techniques/T1003/001/) | Sysmon Event ID 10 - LSASS access<br>Suspicious GrantedAccess values |
| 6 | Lateral Movement | [T1021.002](https://attack.mitre.org/techniques/T1021/002/) | SMB connections to multiple hosts<br>Remote service creation<br>PsExec service installation |
| 7 | Data Exfiltration | [T1048.003](https://attack.mitre.org/techniques/T1048/003/) | Unusually long DNS queries<br>High volume of DNS traffic<br>Base64-like subdomains |
